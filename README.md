## 📋 Submission Guidelines

Follow these steps carefully to ensure your submission is valid:

1. **Create a GitHub repository** named in this format:
   ```
   TJ-Tasks-2026-<Your_Name>
   ```

2. Add a **compulsory `README.md`** file that includes:
   - Your approach and algorithm
   - Screenshots of your final outputs (questions / websites / apps / results)

> ⚠️ Submissions are **only valid** through GitHub.
