# Game Development Tasks

Welcome! These tasks are designed to introduce you to game development through small, achievable projects. You may use **any game engine** of your choice, including **Unity, Unreal Engine, Godot, GameMaker, Construct, Defold, or others**.

The goal is not perfection, but to learn core game development concepts while creating something fun and playable.

---

# Task 1: Pong Clone

## Objective
Recreate the classic Pong game with two paddles and a bouncing ball.

## Requirements
- Create two paddles and one ball.
- The ball should bounce off paddles and screen boundaries.
- A score should be tracked for each player.
- Reset the ball after a point is scored.
- The game must be fully playable.

## Bonus
- Add sound effects.
- Add a start menu.
- Increase ball speed over time.

# Task 2: Flappy Bird Clone

## Objective
Create a Flappy Bird-style game where the player navigates through obstacles and tries to achieve the highest score.

## Requirements
- Player can control the bird.
- Gravity affects the bird's movement.
- Pipes/obstacles spawn continuously.
- Score increases when passing obstacles.
- The game ends when the player collides with an obstacle or the ground.

## Bonus
- Save and display the highest score.
- Add sound effects and visual effects.
- Add a day/night background cycle.

# Task 3: Brick Breaker

## Objective
Create a Brick Breaker game where the player destroys bricks using a ball and paddle.

## Requirements
- Player controls a paddle.
- Ball bounces realistically off surfaces.
- Bricks are destroyed when hit.
- Display the player's score.
- The level is completed when all bricks are destroyed.
- The game must be fully playable.

## Bonus
- Add power-ups.
- Add multiple levels.
- Add different brick types.
- Add sound and particle effects.
