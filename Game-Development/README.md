# Game Development Tasks

Welcome! These tasks are designed to introduce you to game development through small, achievable projects. You may use **any game engine** of your choice, including **Unity, Unreal Engine, Godot, GameMaker, Construct, Defold, or others**.

The goal is not perfection, but to learn core game development concepts while creating something fun and playable.

---

## 🌟 Task Categories

We've divided the tasks into three levels: **Easy, Medium, and Hard**.

Each level introduces new game development concepts and gives you more freedom to experiment.

| Level | Difficulty | Focus |
| ------- | ---------- | ----------------------------- |
| 🟢 **Level 1** | Easy | Input, Collision, Scoring |
| 🟡 **Level 2** | Medium | Physics, Obstacles, Game States |
| 🔴 **Level 3** | Hard | Simple AI, Simple Combat, Health Systems |

> 💡 **You don't need to complete everything.** Pick a level that matches your current experience and challenge yourself!

---

## 🧠 What You'll Learn

## 🟢 Level 1 — Pong Clone

### 🎯 Objective

Recreate the classic Pong game with two paddles and a bouncing ball.

### ✅ Requirements

- Create two paddles and one ball.
- One paddle is controlled using **W** and **S**, while the other is controlled using the **Up Arrow** and **Down Arrow** keys.
- The ball should bounce off paddles and screen boundaries.
- A score should be tracked for each player.
- Reset the ball after a point is scored.
- The game must be fully playable.

### ⭐ Bonus

- Add sound effects.
- Add a start menu.
- Increase ball speed over time.

---

## 🟡 Level 2 — Flappy Bird Clone

### 🎯 Objective

Create a Flappy Bird-style game where the player navigates through obstacles and tries to achieve the highest score.

### ✅ Requirements

- Player can control the bird using the **Space Bar**.
- Gravity affects the bird's movement.
- Pipes/obstacles spawn continuously.
- Score increases when passing obstacles.
- The game ends when the player collides with an obstacle or the ground.
- The game must be fully playable.

### ⭐ Bonus

- Save and display the highest score.
- Add sound effects and visual effects.
- Add a day/night background cycle.

---

## 🔴 Level 3 — Top-Down Survival Game

### 🎯 Objective

Create a top-down survival game where the player must survive against continuously spawning enemies for as long as possible.

### ✅ Requirements

- Player can move using **WASD**.
- Player always faces the **mouse cursor**.
- Player can shoot in the direction of the mouse using **Right Mouse Click**.
- Enemies spawn periodically.
- Enemies move towards the player.
- Player has a health system.
- When an enemy touches the player, the player's health should decrease.
- Display the player's score or survival time.
- Game over when health reaches zero.
- The game must be fully playable.

### ⭐ Bonus

- Add multiple enemy types.
- Add collectible health pickups.
- Add a wave system with increasing difficulty.
- Add sound effects and visual effects.

## 📋 Guidelines

- You must use a game engine to complete your project (Unity, Unreal Engine, Godot, GameMaker, Construct, Defold, or any other game engine).
- You may use AI tools (ChatGPT, Gemini, Claude, Copilot, etc.) to learn concepts, solve problems, and assist with development.
- If you use AI-generated code, make sure you understand what it does and can explain it.
- You may use tutorials, documentation, videos, and other learning resources.
- Feel free to add your own ideas, mechanics, or improvements beyond the listed requirements.
- Focus on learning and building rather than making a perfect game.

## Final Note

Remember: every game developer starts with simple projects.

The purpose of these tasks is not to create a polished game, but to learn how games are built, one system at a time. Focus on making your game playable, understanding the concepts involved, and enjoying the process of creation.

Don't be afraid to experiment, make mistakes, or add your own ideas. Creativity and curiosity are just as important as technical skills.

Most importantly have fun building your game! 🎮
