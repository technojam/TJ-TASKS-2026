## 5. Suggested Learning Order

If you are completely new to Web3, follow these resources in order:

1. Read the Bitcoin whitepaper and understand the basic idea behind decentralized digital money.
2. Learn Ethereum fundamentals: accounts, transactions, blocks, and smart contracts.
3. Learn basic Solidity syntax.
4. Learn smart-contract security fundamentals.
5. Learn the Solana account and program model.
6. Learn the basic Rust concepts required for Solana development.
7. Learn Anchor fundamentals.
8. Build and deploy a simple Solana program on Devnet.
9. Learn how frontend applications interact with wallets and blockchain programs.
10. Explore more advanced smart-contract and dApp development.

## 8. Important Notes

- Use Ethereum testnets such as Sepolia for EVM-based tasks.
- Use Solana Devnet for Solana-based tasks.
- Never share your private key or seed phrase.
- Never use real funds for the audition tasks.
- Do not blindly copy code from tutorials.
- You should be able to explain every important part of the code you submit.
- You are encouraged to use official documentation as your primary source of truth.
- AI tools may be used for learning and debugging, but you must understand and be able to explain your submitted implementation.

## 9. What You Should Know Before Submission

By the end of the tasks, you should be comfortable explaining:

- What a blockchain is.
- How transactions work.
- What a wallet actually does.
- What a digital signature is.
- How smart contracts work.
- What Ethereum accounts and transactions are.
- What Solana accounts and programs are.
- How Solana differs from Ethereum.
- How a frontend communicates with a blockchain.
- What gas/transaction fees are.
- How blockchain state is stored.
- What blockchain events are.
- Why smart-contract security matters.
