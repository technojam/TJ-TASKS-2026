## 🎯 The Mission Blueprint

Your objective is simple: build cool stuff using modern stacks, high vibes, and zero existential dread. The challenge is divided into three levels of escalating chaos: **Easy**, **Medium**, and **Hard**. 

---

## 🟢 Part 1: Easy — The "Hello World" of Flexing
### **Project: The Matrix-Inspired Aesthetic Terminal / Bio-Card**

* **The Vibe:** Dark hacker aesthetic, neon green and black digital design elements, smooth typography, and absolutely zero corporate blandness. 
* **The Task:** Build a sleek, interactive web profile card or mini-terminal that looks like it belongs in *The Matrix*. It should feature:
  * A glowing Matrix-style rain or digital background animation.
  * Interactive buttons that output absurd, humorous developer quotes or Easter eggs when clicked.
  * Responsive design that doesn't break when someone views it on an overpriced smartphone.
* **Suggested Tech Stack:** HTML5, Tailwind CSS, Vanilla JavaScript or basic React/Next.js.
* **Humorous Evaluation Metric:** If the hiring manager opens it and immediately feels the urge to put on sunglasses indoors, you get full marks.

---

## 🟡 Part 2: Medium — The Mid-Life Crisis of Logic
### **Project: The Over-Engineered 3D Scientific Calculator**

* **The Vibe:** Why build a flat, boring calculator when you can make one floating in pseudo-3D space that computes sine waves like a particle accelerator?
* **The Task:** Build a scientific calculator with a twist:
  * Render it with a gorgeous 3D tilt/depth effect (think Three.js or smooth CSS perspective/transforms).
  * Include standard scientific functions (sin, cos, tan, log, square roots) plus a custom, highly sarcastic error message handler (e.g., trying to divide by zero shouldn't just show `Infinity`; it should display *"Bro, you just tore a hole in the spacetime continuum. Good job."*).
  * Smooth animations on every button press.
* **Suggested Tech Stack:** Next.js / React, Three.js (or React Three Fiber / Tailwind), and a healthy amount of CSS grid magic.
* **Humorous Evaluation Metric:** If pressing `9 + 10` does *not* output `21`, or if dividing by zero doesn't trigger a mock self-destruct countdown, points will be deducted.

---

## 🔴 Part 3: Hard — Entering the Matrix (Agentic & Full-Stack Chaos)
### **Project: The Local LLM-Powered AI Agent / UI-Control Dashboard**

* **The Vibe:** You are now playing God. You are wiring up a local or cloud large language model to orchestrate a smart dashboard that actually triggers actions, controls local UI states, or fetches wild payloads based on natural language prompts.
* **The Task:** Build a full-stack application featuring:
  * A chat interface connected to an LLM backend (using FastAPI / Next.js API routes, optionally hooking into local orchestration tools like Ollama).
  * An agentic capability where typing commands like *"Make the dashboard background red and summarize my life choices"* dynamically manipulates the frontend DOM elements or pulls mock analytics data.
  * Error recovery: When the model inevitably hallucinates a JSON response, your backend needs to gracefully catch it instead of throwing a tantrum.
* **Suggested Tech Stack:** Next.js (Frontend), FastAPI (Python Backend), Tailwind CSS, and local LLM integration (Ollama / OpenAI API).
* **Humorous Evaluation Metric:** If your AI agent starts talking back to you, questions your coding standards, or refuses to run code until you ask nicely, you achieve legendary status.
