# App Development Tasks - 2026

We have prepared 3 App Development tasks according to their respective difficulty levels.

**Note:** Candidates may use **Kotlin, Swift, Flutter, or React Native**.

---

## Easy - App Development Fundamentals

### Task: Build a Calculator App

Create a simple calculator mobile application.

### Requirements

- Display numbers and operators.
- Perform:
  - Addition
  - Subtraction
  - Multiplication
  - Division
- Include clear/reset functionality.
- Create a clean mobile UI.
- Run the app on an emulator or physical device.
- Push the project to github

### Bonus

- Add dark/light mode.
- Add calculation history.

## Medium - App Development & Local Storage

### Task: Build a Notes App

Create a simple notes mobile application.

### Requirements

- Add a search option.
- Store notes locally so they remain after restarting the app.

## Hard - API & Advanced App Development

### Task: Build a GitHub Profile Explorer App

Create a mobile application that allows users to search for GitHub profiles.

### Requirements

- Create a search screen.
- Use the GitHub REST API.
- Display:
  - Profile picture
  - Username
  - Name
  - Bio
  - Followers
  - Following
  - Public repositories
- Add navigation between screens.
- Create a clean mobile UI.
- Run the application on an emulator or physical device.
- Push the project to github.
